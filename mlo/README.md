# Nocturne Lounge — FiveM MLO

Original premium underground lounge designed for GTA V/FiveM.

## Production target
- High-detail architecture and furnishing
- PBR-style materials and authored color palette
- Layered practical/accent lighting
- Game-ready optimization
- Collision, LOD and occlusion planning
- Sollumz/CodeWalker export pipeline for YTYP/YMAP/YBN

## Current stage
The first procedural production pass builds the complete spatial layout, hero props, lighting fixtures, decorative assets and a Blender showcase render.

## Build
Run `mlo/scripts/build_mlo.py` with Blender 5.2.x. Outputs are written to `D:\first Blender\mlo\output` on the production PC.
